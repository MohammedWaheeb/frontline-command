# Ground-launcher payload pose candidate

Historical private candidate based on the exact v24 client. All four matching full art handoffs and scoped native/browser courses subsequently completed; the exact runtime delta is integrated in `work/ground-launcher-integration-v1`. Go and frozen products remain unchanged. This is component acceptance, not a complete-game claim.

Owned US, SY and SA launchers select empty payload variants for mobile,
deployment and packing states. IR additionally selects a one-charge variant;
the first actual volley event retains one missile and the second event consumes
it. Cue clocks stay canonical and follow distinct Go events. Ownership is
checked on every selection. Structural/deployment interruptions discard old
firing cues; asynchronous page loading cannot retain stale payload pixels.

The matching art proposal is in `work/art/ground-launcher-charge-contract-v1`.
Until those variants exist, the explicit `missingPayloadArt` diagnostic remains
an incomplete-art failure for release purposes, even though the development
renderer can fall back to generic art.
