Private test-only course. **No browser, HTTP host or native simulation has been launched.** Root must provide and approve a fresh immutable ordinary `make build` package, its `version.json` digest, matching protocol source and genuine Chrome executable pins, then release the sole browser lane. Placeholder config intentionally fails admission. Product-specific preflight is pending that handoff.

The course performs normal UI actions in one fresh page/App: menu → standard-quality Copper Junction solo skirmish (zero AI, normal field practice) → select engineering rig and center its real production facility → Power station → at most 24 pointer previews → one click at an actual clear Go preview → complete paid power → normal pause/save → return to command center. It never calls App internals, sends an RPC/order itself, edits world/view/save state, changes rules, waits for a fabricated result or claims a combat victory. A rejected order or absence of a clear site fails this bounded fixture; there is no automatic retry/extra building.

The passive worker decoder sees actual owner snapshots, the App's original submitted batch and authoritative receipt. The normal saved engine's **owner power records only** establish the paid amount against the real Go content catalog. Foreign save state is not used for decisions or retained in the evidence. Worker messages, transfer objects and results remain original. Menu cleanup verifies the observed Go workers terminate and battlefield DOM disappears. It does not claim all JavaScript/art/image caches are empty.

## Body evidence and strict diagnostics

The six frozen helpers originate in `work/multiplayer-current-loader-diagnostic-v2/helpers`. The only consumed-body helper change introduces default-off local Blob reading; this course does **not** read a returned Blob again. The observer follows the original explicit reader chunks, native `arrayBuffer()`/`bytes()` results, exact EOF and incremental SHA without retaining chunks. It preserves response/reader/result/error identities. There is no clone, tee, new product fetch, response interception, fake cancellation or JSON reserialization. Native Blob/JSON/text/formData, HTML image/SVG/CSS/script consumption, worker/service-worker and unproved realms remain explicit unsupported coverage.

Each failed request fact requires a unique native target/context/frame/RequestId, full URL/method/document ordinal, non-overlap, status 200, no redirect/service worker, original-consumer completion, and exact preselected bytes/SHA. EOF-before/after-error ordering is retained. It never infers a cancellation cause or decode success. Every product raw failure remains a strict failure regardless of complete body evidence. Successful unsupported/ambiguous consumers are coverage limits, not corruption. Proven size/hash mismatch is independently fatal.

After normal menu cleanup, four tiny uniquely addressed same-origin controls consume one original reader each: valid, truncated transfer, closed connection, wrong expected SHA. Exact control URLs and codes are separately reported; unrelated diagnostics cannot be excluded. Negative tests also cover ambiguous **failed** JSON, missing EOF/realm/unique ID, overlap, service worker, overflow, capture failure and original object/error forwarding. Reconciliation runs **after** page/context/browser/server closure so late events remain part of the result. Earlier failed/unclassified evidence is untouched.

## Resource and readiness measurements

`resource-health.mjs` observes page-realm native WebGL creation/deletion, bindings and texture/buffer/renderbuffer allocation sizes. It uses weak references for contexts/canvases and never retains GL objects, invokes `getError`, forces GC or submits draws. It estimates known texture formats/mips and buffer sizes; unknown formats remain unknown. The counts are **not actual GPU totals**, ArtLibrary atlas residency, driver backing allocations or all browser/worker caches.

Snapshots at initial menu, scene ready, completed power and menu-after-release include these counters, live battlefield context resource IDs, connected canvases, CDP heap/DOM/task metrics and bounded page RAF intervals. Page RAF intervals include observer overhead and host scheduling; they are not renderer CPU cost or frame-time certification. A 10-second asynchronous cleanup observation reports zero live tracked GL objects, actual context loss, or collected context; residue stays unresolved/failing. It never forces context loss or GC to satisfy the gate. The current source's same-generation cameo cache is expected to persist. Shared Blender conditions preclude reference performance acceptance.

Limits: 16,000 packaged files/2 GiB encoded product; sequential file hashes; 120-second preflight; one browser/240-second course; 64 MiB observed body/2 GiB cumulative hash bytes/16 simultaneous hashes; 16,384 records; zero retained response chunks and disabled Blob local reads; 16 GL contexts/16,384 tracked resources; last 2,048 RAF intervals; 256-byte controls; explicit closure watchdogs. Overflow is incomplete evidence. The static fixture streams 64 KiB chunks and uses production's `no-store` response policy. It is not a network Go host.
