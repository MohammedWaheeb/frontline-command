# Source scope for the measurements

Read-only review of current source; hashes are in `source-audit.json`. The future package may have later source and must be pinned separately. No renderer, asset, UI, runtime or packaging changes from this lane.

- `BattlefieldRenderer.dispose()` aborts listeners, detaches minimap, destroys actors/deaths/environment, shadow resources, terrain chunks/baker, tactical/placement/strike/combat resources, then destroys its Pixi application/canvas. This justifies observing detached battlefield canvas plus tracked native GL release; it does not prove byte-perfect global memory reclamation.
- `BattleController.dispose()` removes frame subscription and disposes its renderer, then schedules `Application.releaseBattlefieldArt()`. The Application chains art cleanup; the renderer's effect disposal is also asynchronous. Hence the bounded post-menu observation instead of an immediate zero assertion.
- `ArtLibrary.release()` clears sheet ownership, awaits pending sheet values and disposes them serially behind prior release work. `SpriteSheet.dispose()` aborts its lifetime, settles pending loads, unloads pages and awaits unloads. Page-owned texture disposal calls `texture.destroy(true)` and `bitmap.close()`. `clearImages()` and full generation disposal have broader lifetimes; ordinary match release explicitly retains same-generation cameos.
- `ArtLibrary.statistics` counts world atlas RGBA bytes and alpha masks, not the entire GL allocation pool. `trim()` has 192 MiB standard/384 MiB high soft atlas budgets and evicts only pages idle for ten seconds. Those are **not** hard native GPU totals, so this observer does not pretend that its aggregate GL estimate is the same metric.
- The menu diorama uses 2D Canvas and retains generation-scoped resources separately. Page GL counters do not observe its 2D backing storage, native image decoder/cache storage, worker allocations or audio buffers. CDP page heap measurements are diagnostics, not proof those consumers are absent.
- Production `Server.ServeHTTP` supplies `Cache-Control: no-store`; this private static server matches that policy, but does not certify network host behavior. The loaded App's simulation is the exact packaged Go WASM.

The additional packaging `make test` dispatcher was reviewed without rerunning root's tests: `execFileSync` executes the three explicit packaging test files and propagates failure before the retained Go tests/vet and client checks. Root's new `commandHasOutput` drains stdout without retaining it, bounds stderr, waits for process close, and rejects nonzero/spawn failure. Awaiting it for `source_dirty` preserves Git porcelain semantics while avoiding the former 1 MiB capture limit. No blocker found; no new command timeout was introduced, matching prior behavior.
