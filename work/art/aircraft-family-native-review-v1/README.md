# Native aircraft family comparison

The helper adapts the accepted infantry matrix contact method: exact atlas crops, the frozen tint/shadow compositor, and the packed ground anchor. No resampling, size normalization, source edits, or runtime publication occurs.

`available7-v1` pins catalog56 and seven complete aircraft handoffs. Its six images show heading3 flight, empty flight (or explicitly labeled unarmed parked), and service frame3 at both native qualities. The five unfinished aircraft are listed in result.json; they are not represented by pilots or active raw files.

The generic armed service frame is intentionally loaded; owned zero-ammo lifecycle is a separate runtime contract. These ground-level source composites do not simulate flight altitude. All per-asset review limits remain unchanged. The helper rejects missing tuples, duplicate frames, changed source hashes and any cell clipping. Later coverage uses a fresh output directory, preserving this snapshot.
