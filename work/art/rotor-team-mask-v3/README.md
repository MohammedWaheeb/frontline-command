# Opacity-aware team mask: isolated two-pass candidate

The original helper flattens every non-team surface to opaque Holdout, so alpha0.09 rotor discs incorrectly erase visible ownership paint. The mixed Holdout candidates in v1/v2 restore paint but create black alpha under overlapping discs; both were rejected and preserved.

This candidate delegates all opaque scenes to the exact original render function. For a team pass containing translucent non-team pieces, it first renders the original shaded white paint with those pieces hidden, then a separate linear emission coverage pass with white team surfaces, black plain surfaces and true source opacity. No Holdout is used in coverage. Denoising and display dither are disabled only for mathematical coverage; the initial attempt with denoising produced colored edge values and remains preserved. The source-compatible PNG helper replaces alpha with premultiplied linear white coverage while preserving every shaded RGB byte and original PNG ancillary chunk.

Materials, object visibility, camera visibility, samples, transparent-ray limit, output path/format, view transform/look/exposure/gamma, denoising, dither and ground visibility restore in `finally`. The injected late coverage-write failure confirms those restorations. No model, world scale, anchor, camera, simulation state or shipping helper is changed.

All28 original function/class definitions, including the renamed original render function, are AST-exact. Four standard-library PNG tests cover all5 row filters, exact RGB/ancillary preservation, alpha arithmetic and rejected corruption/dimensions/chromatic coverage. The stacked controls pass25 checks for source alpha0/.09/.5/1,1/4/8 planes, absent plain-surface mask and failure restoration. Strict independent render byte comparisons remain separately marked FAIL; they are not relabeled as passes. The prior measured128px quantization envelope is not generalized to actual aircraft images.

The actual pilot compares20 world views plus normal airlift portrait/cameo, retaining40 old/repeat source controls byte-exact. Native composites, black-alpha regression checks, genuine source-opacity behavior and actual repeat statistics must pass review before promotion. The extra coverage render affects an estimated2,880 new rotorcraft poses; whole-production timing must include it. This is a candidate pipeline fix, not completed aircraft art or final release acceptance.
